# mle-analiz-loyalnosti-polzovatelej

Пайплайн анализа лояльности пользователей Яндекс-Афиши
Класс DataProcessor выполняет следующие шаги:
Загрузка данных из PostgreSQL (Яндекс Облако) через SQLAlchemy с SSL-шифрованием.
Загрузка курсов тенге из CSV для конвертации валют.
Выполняется предобработка: конвертация валют, нормализация текста, преобразование типов, фильтрация выбросов (99-й перцентиль), удаление явных и неявных дубликатов.
Построение профилей пользователей: агрегация по user_id, определение первого заказа, фильтрация аномалий (>99 перцентиля заказов).
Расчёт Retention по сегментам (тип первого мероприятия, устройство, регион, дни недели).
Корреляционный анализ phi_k по сегментам количества заказов.
Формирование текстового отчёта в терминал.

Безопасность
Пароли и credentials вынесены в файл .env и подгружаются через python-dotenv.
Файл .env и папка data/ добавлены в .gitignore и не попадают в репозиторий.


Для запуска:
1. Клонировать репозиторий и перейти в папку проекта
2. Создать и активировать виртуальное окружение venv
3. Установить необходимые библиотеки из файла requirements.txt
4. Запустить приложение командой python main.py
