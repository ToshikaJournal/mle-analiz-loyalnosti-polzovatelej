# mle-analiz-loyalnosti-polzovatelej

Пайплайн анализа лояльности пользователей Яндекс-Афиши
Цель проекта — выявить факторы, влияющие на возврат пользователей, и сформулировать бизнес-рекомендации для увеличения retention.

Класс DataProcessor выполняет следующие шаги:
Загрузка данных из PostgreSQL (Яндекс Облако) через SQLAlchemy с SSL-шифрованием.
Загрузка курсов тенге из CSV для конвертации валют.
Выполняется предобработка: конвертация валют, нормализация текста, преобразование типов, фильтрация выбросов (99-й перцентиль), удаление явных и неявных дубликатов.
Построение профилей пользователей: агрегация по user_id, определение первого заказа, фильтрация аномалий (>99 перцентиля заказов).
Расчёт Retention по сегментам (тип первого мероприятия, устройство, регион, дни недели).
Корреляционный анализ phi_k по сегментам количества заказов.
Проверка двух продуктовых гипотез о влиянии на возврат пользователей: Спорт vs Концерты, ТОП-3 региона по количеству пользователей VS остальные.

Формирование текстового отчёта в терминал.

Безопасность
Пароли и credentials вынесены в файл .env и подгружаются через python-dotenv.
Файл .env и папка data/ добавлены в .gitignore и не попадают в репозиторий.


Для запуска:
1. Клонировать репозиторий и перейти в папку проекта
2. Создать и активировать виртуальное окружение venv
3. Установить необходимые библиотеки из файла requirements.txt
4. Создать файл .env  в корне проекта и заполнить своими данными для подключения к PostgreSQL
5. Запустить приложение командой python3 main.py
    
ИТОГОВЫЕ ВЫВОДЫ:
Проанализировав 287 185 заказов 21 474 пользователей Яндекс Афиши, мы выяснили, что 61.5% клиентов возвращаются за повторной покупкой, причем лучшими «точками входа» стали Выставки (64.2%), Театр (63.5%) и Desktop-устройства (64.0%), тогда как Спорт и сезонные «Ёлки» показывают худшее удержание. 

Проверка гипотез
- опровергла, что на спортивные мероприятия(56,1%) пользователи возвращаются чаще чем на концерты(61.8%)
- а в ТОП-3 регионах гипотеза подтвердила, что возврат чуть выше, чем в остальных (63.2% против 59.5%).

Повторные покупки (5+ заказов) имеют высокую корреляцию с регулярностью посещения (phi_k ≈ 0.697), поэтому для роста удержания рекомендуется внедрить персональные скидки на второй заказ в короткий промежуток, после последней покупки, активнее продвигать категории «Выставки» и «Театр», улучшить мобильный пользовательский путь и ввести накопительную систему бонусов для постоянных клиентов.
